# First-Person Portal Chambers

We will build the Portal clone as a first-person 3D browser game with visible portal windows, momentum-preserving traversal, weighted cubes, pressure buttons, chamber exits, and a double-clickable `file://` root `index.html`. This is more demanding than a top-down abstraction or dev-server-only demo, but it preserves the core Portal fantasy: seeing and moving through linked spaces in a real test chamber.
